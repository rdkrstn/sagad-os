# Roadmap

## v0.1 Boundary

| Include | Exclude |
|---|---|
| Chatwoot adapter | Native Intercom adapter |
| Twenty CRM adapter | Full CRM replacement |
| Two agents | Agent marketplace |
| Knowledge upload / retrieval | Complex fine-tuning |
| Approval queue | Workforce scheduling |
| Audit logs | Full QA scoring engine |
| Basic reports | Enterprise BI |
| Docker setup | Kubernetes-first deployment |
| Seed demo data | Production migration tooling |
| Contributor docs | Paid cloud platform |

## Next Milestones

1. Prove the live Chatwoot to Agent Studio to approval loop.
2. Enable Twenty read-only context safely.
3. Persist audit events and conversation state.
4. Move governed retrieval to Postgres `pgvector`.
5. Add more adapter examples after the boundary is stable.
